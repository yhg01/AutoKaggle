    Frame the problem

    Describe the decision that better predictions would support.

    Budget for one credible attempt

    Include experiments and final evaluation. Give a US dollar amount or range. “Unknown” is a valid starting point.

    02

    Understand the data

    Establish where the data came from and who can use it.

    Add a dataset

    CSV format · up to 200 MB

    For larger files, paste a Google Drive link in the interview. Set General access to “Anyone with the link” and the role to “Viewer”. Drive links are saved for review; automatic import is not yet available.

    03

    Design the evaluation

    Choose the prediction target and the conditions the model must handle.

    Use random rows only when observations are independent.

    Keep observations from the same patient, site, or source together.

    Use later observations as the held-out test set.

    80% trainingShared with the researcher20% hidden testOrganizer access only
    Exclude columns from model inputs

    Remove identifiers, answer proxies, and information unavailable at prediction time.

    Add a dataset to select columns.

    Group splits can be approximate. Final test rows are kept out of the baseline trial.

    04

    Run a trial

    Check for data problems and compare a baseline with a simple reference.
