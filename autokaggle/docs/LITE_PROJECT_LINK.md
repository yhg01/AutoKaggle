# Link Lite evaluations to BOLD OS projects

Lite asks for the owning BOLD OS project with the research question after the opening source questions. Supply the project page link, for example `https://bold-lab-ai.github.io/bold-os/project.html#id=<id>`. Links with a publication board and a tab are supported.

The field is part of the accepted contract and the Research objective checklist. It is required before package preparation, including for saved sessions that lack it. Existing messages and results remain available. The agent must ask for the project link; it must not infer it from a paper or repository. The researcher accepts it with the other proposed contract changes.

AutoKaggle validates the link format. The Problem Bank registration service must check that the project exists. A valid URL alone does not prove project membership or access.

## Checks

On 13 November 2026, 70 project-link and Lite tests passed. A live DeepSeek V4 Pro interview asked for the missing project, then recorded the supplied project URL. It kept a separate unresolved scientific source question open. DeepSeek was used under the owner's temporary provider instruction; this run does not claim OpenRouter coverage.
