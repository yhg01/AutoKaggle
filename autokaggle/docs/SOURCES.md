# AutoKaggle source register

Checked online on 26 October 2026. This register supports [RESEARCH.md](RESEARCH.md). Sources below are organizer accounts, official documentation, original research, or first-hand reports acknowledged in the benchmark repository. It is not an interview transcript or a copy of Kaggle's internal procedure.

## Evidence boundaries

The workflow, prototype choices, acceptance tests, interview plan, and noise-data experiment in the main report are our recommendations. They are not presented as quotations or a discovered private standard. The report uses short paraphrases, with no extended source excerpts.

The random-noise interval is a direct calculation under independent binary labels. It is a reference for one run, not a universal cheating threshold. Dataset dependence, many trials, adaptive feedback, and altered class probabilities change the interpretation.

An available source URL establishes that evidence was found. It does not establish permission to copy a dataset, completeness of an audit, or validity of an individual scientific task.
